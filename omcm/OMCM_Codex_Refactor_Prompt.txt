## 5. CLINIC PLACEMENT OPTIMIZATION PANEL

## 6. SIMULATION MODE / SCENARIO BUILDER

Do not claim Google Routes API can accept arbitrary custom road closures directly. - Reduced clinic count / vehicle unavailability scenario.
- Run Scenario action: derive scenario-adjusted scores, exclude affected sites/routes, rerun optimization, compare baseline versus scenario (changed sites, covered/unserved population, travel time, flood-safe accessibility).
- Reset Scenario action: clear all simulated changes without touching actual data or approved deployments.
- Clear before/after visuals and readable reasons for changed recommendations.

## 1. PROJECT OVERVIEW

OMCM is a data-driven healthcare resource planning platform designed to help Philippine Local Government Units (LGUs) determine the best locations for deploying mobile healthcare clinics.

Imagine that Laguna has 20 barangays requiring medical assistance but only three available mobile clinics.

The application should analyze healthcare needs across barangays and recommend the best clinic locations based on:

- Disease prevalence and estimated disease risk
- Population size and density
- Vulnerable residents, including children and elderly people
- Poverty levels
- Accessibility of existing hospitals
- Flood hazards and weather conditions
- Road accessibility and travel time
- Number and capacity of available mobile clinics

The main objective is to maximize the number of high-priority residents who can access mobile healthcare services while respecting safety, travel-time, and clinic-capacity restrictions.

The system should also allow users to simulate disasters such as flooding, road closures, or clinic shortages.

The application is a decision-support system, not an autonomous medical decision-maker. Final deployment decisions must remain with authorized LGU administrators.

## 5. FEATURE 2 — HEALTHCARE NEED SCORING

Implement a Python-based scoring engine.

Each barangay should receive a healthcare need score from 0 to 100.

Use an initial weighted scoring formula:

- Disease risk: 30%
- Vulnerable population: 25%
- Hospital inaccessibility: 20%
- Poverty: 15%
- Flood exposure: 10%

These weights are illustrative and must be adjustable, not presented as scientifically validated values.

Normalize the indicators before combining them.

Make sure higher values consistently indicate greater healthcare need.

Calculate an appropriate disease burden indicator using available case counts and population, rather than comparing raw case counts alone.

The system should:
- Automatically calculate scores.
- Rank barangays by healthcare need.
- Display contributing factors.
- Allow administrators to adjust the weights.
- Immediately recalculate scores when weights change.
- Handle missing data gracefully.
- Display warnings when data is estimated or incomplete.

Provide explanations such as:

"Barangay A has a high healthcare need because of elevated disease risk, limited hospital access, and a large vulnerable population."

Keep the scoring logic transparent and easy to understand.

## 6. FEATURE 3 — OPTIMAL MOBILE CLINIC PLACEMENT

This is the most important feature.

Use Google OR-Tools to implement a capacity-aware maximum coverage optimization model.

### Administrator inputs

- Number of available mobile clinics
- Capacity of each mobile clinic
- Maximum acceptable travel time
- Available staging locations
- Healthcare priority weights
- Road restrictions
- Flood-related restrictions

### Optimization goal

Find the combination of clinic locations that serves the greatest amount of priority-weighted healthcare demand.

### Required constraints

- Do not select more clinics than are available.
- Only choose eligible staging locations.
- Respect each clinic's daily patient capacity.
- Respect the selected maximum travel time.
- Exclude flooded or inaccessible staging sites.
- Exclude travel paths affected by simulated road closures.
- Do not count the same resident or demand allocation twice.

Use an assignment-based optimization model so that residents can be allocated to eligible clinics without exceeding capacity.

### Output

Display:
- Recommended clinic locations
- Barangays assigned to each clinic
- Estimated number of residents served
- High-priority residents reached
- Expected average travel time
- Unserved demand
- Capacity utilization
- Reasons for choosing each site

Display recommended locations as prominent markers on the map.

Provide a **Generate Optimal Placement** button.

Whenever users change the number of clinics or other parameters, they should be able to run the algorithm again.

### Baseline comparison

Implement a second, simpler allocation method that prioritizes the most populated eligible barangays.

Compare that baseline with OMCM using the same restrictions and inputs.

Show:
- Population covered
- Priority-weighted demand served
- Average travel time
- Unserved demand
- Flood-safe accessibility

Add a comparison chart.

Do not invent an improvement percentage. Calculate it from the actual results generated by the two methods.
